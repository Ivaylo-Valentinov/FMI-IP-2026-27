## Указатели и референции

### Оператор &

-> Взима адреса на променливата  
-> Пример:

```c++
int num = 256;
cout << num << endl; // 256
cout << &num << endl; // 0x7ff7b909f0c8 шестнадесетично число, което представлява адреса на клетката в паметта, в която е записана num
```

### Указатели

-> Променливи, които пазят адрес на друг обект.  
-> nullptr = нулев указател, т.е. указател, който не сочи към никой адрес

```
<тип>* <име> [=<адрес в паметта>];
```

```c++
int a = 5;
int* a_ptr = &a; //указател към адреса на а

int* b_ptr = nullptr; //нулев указател
int b = 6;
b_ptr = &b;
```

### Оператор \* (дереференциране)

-> Приложен към указател, дава достъп до стойността, към която указателят сочи  
-> Чрез него можем както да прочетем, така и да променим тази стойност  
-> Пример:

```c++
int a = 5;
int* a_ptr = &a;

cout << a_ptr << endl;  // 0x7ff7b909f0c8 - адресът на a
cout << *a_ptr << endl; // 5 - стойността на a

*a_ptr = 10; // променяме a през указателя
cout << a << endl; // 10
```

-> Символът `*` има различно значение според контекста:

- в декларация (`int* a_ptr`) - казва, че `a_ptr` е указател
- пред вече съществуващ указател (`*a_ptr`) - дереференцира го
- между две числа (`a * b`) - умножение

-> Дереференцирането на `nullptr` е грешка:

```c++
int* p = nullptr;
cout << *p; // грешка! p не сочи към нищо
```

### Константни указатели и константи

```c++
int * const ptr; // константен указател

const int * ptr; // указател към константа
int const * ptr; // указател към константа

const int * const ptr; // константен указател към константа
```

-> За да го запомним просто четем отдясно наляво:

- `const int * p` - **p** е указател (`*`) към цяло число (`int`), което е константа (`const`)
- `int * const p` - **p** е константа (`const`), която е указател (`*`) към цяло число (`int`)

### Референция

Референцията е допълнителен "етикет" към вече съществуваща променлива. Може да се разглежда като константен указател, но има няколко важни разлики:

-> Трябва да се инициализира при декларацията (`int& r;` е грешка).  
-> Не може да бъде нулева - винаги е свързана с някоя променлива.  
-> Не може да се пренасочи към друга променлива - `r = x;` не "премества" референцията, а записва стойността на `x` в променливата, към която е свързана `r`.  
-> Не е отделна променлива - `&r` връща адреса на оригиналната променлива. Указателят, от своя страна, е самостоятелна променлива със собствен адрес.

```c++
int a = 6;
int& b = a;

b = 7;
cout << a; //7
```

## Функции

-> Декларация

```c++
<връщан тип> <име-на-функцията>(<параметри>);
```

Пример:

```c++
int getLastDigit(int number);
void printMsg();
```

-> Дефиниция

```c++
int getLastDigit(int number) {
    return number % 10;
}
void printMsg() {
    cout << "Hello User" << endl;
}
```

-> Извикване

```c++
int main() {
    printMsg();

    int a = 16;
    cout << getLastDigit(a) << endl;

    return 0;
}
```

-> Фактически и формални параметри  
-> Сигнатура на функция  
-> Подаване на параметрите по стойност, по указател и по референция
