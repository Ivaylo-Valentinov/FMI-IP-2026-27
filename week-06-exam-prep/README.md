```c++

std::cout << (m + 5 == &m[5]) << std::endl;
std::cout << *m << ' ' << m[0] << std::endl;
std::cout << *(m + 5) << ' ' << m[5] << std::endl;
```

```c++

	foo(3.1415);

	return 0;
}
```

### 3. задача

Смешно число е такова число, при което няма две съседни цифри с еднаква четност. Например числото 123 е смешно, но числото 235 не е. Напишете програма, която по подадени две цели числа a и b (a ≤ b) намира сумата на числата в интервала [a, b], чиито сбор на цифрите е смешно число.

### 4. задача

Напишете програма, която прочита от стандартния вход размера на масив от цели числа (цяло число n, 1 ≤ n < 1024), следван от елементите му. След това трябва да се провери дали има число k (0 < k < n), такова че всеки две числа в масива, намиращи се на разстояние k едно от друго, се различават по стойност точно с k (например ако k = 2, то модулът от разликата на числата на позиции i и i + 2 трябва да е 2 за всяко i). Ако има такова k, изведете го на екрана. При повече от една стойност на k с това свойство изведете най-голямата. Ако няма, изведете "No solution".

Пример:  
Вход:

```
5
0 1 2 3 0
```

Изход:

```
2
```

Вход:

```
3
1 1 1
```

Изход:

```
No solution
```

### 5. задача

Напишете програма, която прочита от стандартния вход естествено число n (n < 50000), следвано от n точки, всяка зададена с двете си координати x и y (реални числа).
След това се въвеждат две точки – горният ляв и долният десен ъгъл на правоъгълник със страни, успоредни на координатните оси.
Накрая се въвеждат центърът на кръг (точка) и радиусът му.

Изведете на отделни редове колко от първоначално въведените точки са в кръга, колко са в правоъгълника и колко са и в двете. Точките върху границата се броят за вътрешни.

Пример:  
Вход:

```
5
0 0
1 1
3 1
-1 1
5 5
0 2 4 0
0 0 2
```

Изход:

```
3
3
2
```
